# netmonitor

Программа мониторинга наличия сети интернет для Windows. Непрерывно определяет
**одно из 4 состояний** сети и уведомляет при смене состояния (звук + toast +
иконка в трее + лог).

## Состояния сети

| Состояние | Описание | Иконка |
|-----------|----------|--------|
| `UNRESTRICTED` | Интернет без ограничений | 🟢 зелёная |
| `WITH_VPN` | Интернет без ограничений + активный VPN | 🔵 синяя |
| `WHITELIST` | Ограниченный интернет (белые списки) | 🟡 жёлтая |
| `NO_INTERNET` | Интернета нет | 🔴 красная |

## Как это работает

1. Периодически (по умолчанию каждые 6 сек) проверяет доступность «разрешённых»
   и «запрещённых» хостов по HTTP.
2. Определяет активность VPN по наличию VPN-сетевого адаптера (TAP/TUN/Wintun).
3. По таблице состояний вычисляет текущее состояние.
4. Состояние считается подтверждённым после N (по умолчанию 2) одинаковых
   наблюдений подряд — одиночные провалы не переключают состояние.
5. При подтверждённой смене состояния:
   - показывает toast-уведомление (PowerShell),
   - записывает переход в лог-файл,
   - ждёт `notify_delay_sec` (3 сек),
   - проигрывает звук `C:\Windows\Media\Alarm10.wav`,
   - обновляет иконку в трее.

## Установка

```bash
pip install psutil requests pyyaml pystray Pillow
```

Требуется Python 3.10+ на Windows (используется `winsound`).

## Использование

```bash
# разовая проверка (отладка)
python -m netmonitor.cli --check-once --config config.yaml

# запустить мониторинг с иконкой в трее
python -m netmonitor.cli --config config.yaml

# без иконки в трее
python -m netmonitor.cli --config config.yaml --no-tray

# установить автозапуск при старте Windows
python -m netmonitor.cli --install-startup --config D:/path/to/config.yaml

# удалить автозапуск
python -m netmonitor.cli --uninstall-startup
```

## Конфигурация

См. [`config.yaml`](config.yaml) — все параметры настраиваются: интервал,
таймауты, список хостов, паттерны VPN-адаптеров, флаги уведомлений, задержка.

## Структура проекта

```
netmonitor/
  config.py        # загрузка/валидация YAML-конфига
  checkers.py      # проверка хостов, обнаружение VPN
  monitor.py       # определение состояния + главный цикл
  state_tracker.py # подтверждение смены состояния
  notifier.py      # toast + звук + лог
  tray.py          # иконка в трее (pystray)
  startup.py       # автозапуск (.vbs лаунчер)
  cli.py           # точка входа с флагами
tests/             # 105 тестов (TDD)
SPEC.md            # спецификация задачи
```
